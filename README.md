🧠 Online Mental Health Support & Check-In App (Namibia)
📌 Project Overview

The Online Mental Health Support & Check-In App is a mobile-friendly web application designed to promote emotional wellbeing and mental health awareness in Namibia.
The system provides users with a safe, anonymous space to perform daily mood check-ins, access mental health tips, and find emergency support resources.

This project responds to the growing mental health challenges in Namibia, including stress, trauma, suicide, and gender-based violence (GBV), while acknowledging the limited access to mental health professionals.

🎯 Problem Statement

Mental health challenges are increasing in Namibia, but many people face:

Limited access to psychologists and counselors

Social stigma around mental health

Emotional trauma caused by poverty, unemployment, GBV, and substance abuse

Lack of simple digital tools for emotional self-monitoring

As a result, many individuals do not seek help early.

💡 Proposed Solution

This system provides:

A daily mood check-in feature

Self-help mental health tips

Emergency support contacts relevant to Namibia

A calm, supportive interface designed to reduce anxiety

The application is accessible on any device with a web browser, especially smartphones.

✨ Key Features

Mood selection using emojis

Optional daily reflection notes

Positive mental health tips

Emergency mental health resources (Namibia)

Responsive, mobile-first design

Calm and emotionally supportive color theme

🌍 Namibian Context

Namibia faces increasing mental health concerns, including:

Rising cases of depression, anxiety, and suicide

Psychological trauma linked to gender-based violence

A shortage of mental health professionals

Stigma that prevents individuals from seeking help

This project demonstrates how digital solutions can complement existing mental health services and awareness campaigns in Namibia.

🚀 Deployment

The application is deployed using Vercel and can be accessed via a web browser on both desktop and mobile devices.

Deployment steps:

Push project files to GitHub

Import the repository into Vercel

Deploy instantly with no backend configuration
